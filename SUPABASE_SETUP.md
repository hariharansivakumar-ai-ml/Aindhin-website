
# Supabase Setup Guide for Blogs

Follow these steps to configure your Supabase project for the Aindhin website.

## 1. Create a New Project

If you haven't already, sign up at [supabase.com](https://supabase.com) and create a new project.

## 2. Get API Keys

Go to your project settings -> **API**.
Copy the `Project URL` and `anon public` key.

Create a file named `.env` in the root of your project (`d:\React\Aindhin\.env`) and add:

```env
VITE_SUPABASE_URL=your_project_url
VITE_SUPABASE_ANON_KEY=your_anon_public_key
```

## 3. Create the 'blogs' Table

Go to the **SQL Editor** in your Supabase dashboard and run the following query to create the table and insert sample data:

```sql
-- Create the blogs table
create table blogs (
  id bigint generated by default as identity primary key,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  title text not null,
  author text default 'Aindhin',
  image_url text,
  description text,
  slug text unique not null,
  published_date date default packet_date
);

-- Enable Row Level Security (RLS)
alter table blogs enable row level security;

-- Create a policy to allow anyone to read blogs
create policy "Enable read access for all users" on blogs
  for select using (true);
```
